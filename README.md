# Vogue Image Design

Hair & beauty salon website for Vogue Image Design, Main Street, Wicklow Town, Co. Wicklow.

## Stack

- [Astro](https://astro.build) + TypeScript
- [Tailwind CSS v4](https://tailwindcss.com)
- [GSAP ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/) for scroll animations
- [Lenis](https://lenis.darkroom.engineering/) smooth scrolling (`lerp: 0.08`)
- Deployed on Vercel

## Development

```sh
npm install
npm run dev      # local dev server
npm run build    # production build to ./dist
npm run preview  # preview the production build
```

## Notes

- **Booking widget**: `/booking` contains a placeholder div — replace it with the Fresha
  embed from app.fresha.com → Marketing → Booking widget.
- **Contact form**: demo only; it opens the visitor's email app via `mailto:`.
